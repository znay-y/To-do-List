# Java To-Do List

This is a basic CLI java to-do list that lets users interact with a basic todo list through the command line.

# Installation

1. Clone the repository to your local machine using `git clone <repository-url>`.
2. Navigate to the project directory.
3. Compile the Java files using `javac *.java`.
4. Run the application using `java TodoList`.

# Features
- Add new tasks with a name and a description (optional)
- Mark tasks as complete 
- View all tasks showing name, description, and completion status
